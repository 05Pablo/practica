Cómo funciona

Todo el sistema, de los datos a la predicción. Cada paso está en el repositorio.

  1. 1

    Datos

    Artículos de Vikipedio descargados con su API y divididos en párrafos.

    scripts/build_dataset.py
  2. 2

    Librería NLP

    Tokenizador, POS, lematizador y stop-words por reglas, sin spaCy ni NLTK.

    esperanto_nlp
  3. 3

    TF-IDF

    Cada párrafo se convierte en un vector de lemas ponderados.

    TfidfVectorizer
  4. 4

    Modelo

    Se comparan Naive Bayes, Complement NB y regresión logística.

    scikit-learn
  5. 5

    Web

    Se descargan páginas reales y se calcula la probabilidad de cada clase.

    requests + bs4

Dataset

Cada párrafo hereda la clase de la categoría de Vikipedio de su artículo. Formato: CSV UTF-8, separador ;, columnas text;class.

Explora párrafos del dataset

Ruido de etiquetas. Hay párrafos genéricos que no distinguen la clase (p. ej. «Ĝi estis fondita en 1950»), biografías o citas en otros idiomas. El modelo falla en muchos de ellos, y parte de esos errores son de la etiqueta, no del modelo.

La librería esperanto_nlp

API al estilo spaCy: nlp = esperanto_nlp.load(), doc = nlp(texto). Escribe una frase y se analiza aquí mismo: la librería se ejecuta en tu navegador con Pyodide.

    Clasificador

    El modelo entrenado (TF-IDF + regresión logística) se ejecuta en el navegador sobre los lemas que produce nuestra librería.

    Se descarga el texto con la API de MediaWiki, se divide en párrafos (≥ 15 palabras) y se promedian las probabilidades, igual que en el cuaderno.
